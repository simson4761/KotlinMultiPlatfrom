# Kotlin Multiplatform API Sample

This project is a **Kotlin Multiplatform (KMP) sample** created to test and demonstrate a **basic API implementation** using shared networking logic across multiple platforms.

The goal of this project is to explore how API calls, data models, and business logic can be written once in shared Kotlin code and reused on different platforms.

---

## 🎯 Purpose

- Test basic REST API integration in Kotlin Multiplatform
- Share networking logic between platforms
- Understand platform-specific setup for API usage
- Serve as a reference for simple KMP API projects

---

## ✨ Features

- Shared API client in `commonMain`
- HTTP networking using Ktor
- Shared data models
  
---

## 🧩 Supported Platforms

- **Android**
- **iOS**
